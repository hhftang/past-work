# past-work

A collection of scripts from past projects, including:

- **PhD:** R and Python scripts for ML clustering, genomic, and microbiome analyses, as part of a project investigating heterogeneity of childhood asthma.
- **Baker-Cambridge:** selected scripts from polygenic risk score calculation and simulated power calculations for host-viral interaction analysis (to be uploaded).
- **Cancer Council Victoria:** selected R and SAS scripts from the DCPP obesity and stomach cancer project, and the MCCS GI lymphoma project (to be uploaded).

These scripts serve as a record and a representation of the type of work I have done in the past. As such they may not necessarily represent best practice nor how I will approach the same tasks in the present day.

In most cases the scripts will not run as they have been detached from original raw data, in compliance with private and personal information protections.
